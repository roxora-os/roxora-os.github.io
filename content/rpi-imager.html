Repository file

Raspberry Pi Imager can list operating systems from a repository other than Raspberry Pi’s own. Roxora publishes one, rebuilt from the releases every time this site is built:

{{os-list-url}}

It lists the newest image for each board. Imager downloads the image from the release on GitHub and checks it against the checksum in the file before it writes anything.

In the app

  1. Open Raspberry Pi Imager 2 and choose App Options.
  2. Next to Content Repository, choose Edit.
  3. Select Use custom URL, enter the address above, and choose Apply & Restart.
  4. At the device step, choose your board. Then choose the Roxora image and the card or drive to write to.

To go back to Raspberry Pi’s own list, open the same dialog and select Raspberry Pi (default).

From the command line

Start Imager with the repository given as an option. It applies to that run only.

rpi-imager --repo {{os-list-url}}

What to expect

Devices
The device list shows the Roxora boards instead of Raspberry Pi models, and each board shows only its own images.
Radxa ROCK 4D
The ROCK 4D does not boot from an SD card until U-Boot is in its SPI flash. See Booting from an SD card and the Radxa ROCK 4D documentation.
OS customisation
Not offered for Roxora images. At the first login the user is ubuntu with the password ubuntu, and you are asked to choose a new password.
Raspberry Pi
Roxora images do not boot on a Raspberry Pi. With this repository no Raspberry Pi model is in the device list, so there is no way to pick one, but Imager does not check what the card will go into.
Other tools
Imager is optional. The Download page has every image file, and any tool that writes compressed raw images works.
